# Thư mục lưu trữ ảnh mã QR thanh toán (Payment QR Code)

Vui lòng đặt ảnh mã QR ngân hàng của bạn vào thư mục này với tên:
**`payment-qr.jpg`**

- Đường dẫn đầy đủ: `hoian-cooking-class-be/src/main/resources/images/payment-qr.jpg`
- Định dạng: `.jpg` hoặc `.jpeg`
- Tỷ lệ khuyến nghị: Vuông hoặc chữ nhật dọc chuẩn QR code ngân hàng (khoảng 500x500px đến 1000x1000px).
- Hệ thống sẽ tự động nhúng ảnh này vào email thông báo thanh toán định kỳ.
